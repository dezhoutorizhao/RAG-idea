# 阶段性总结

更新时间：2026-05-28

## 1. 当前 Idea

当前方向是 **CSRM-RAG: Counterfactual Set Risk Minimization for Selective RAG**。

核心假设：

> 单个 evidence set 的 sufficiency / relevance 高，并不意味着该 query 在 counterfactual perturbation orbit 下稳定可靠。稳健 RAG 需要评估一个 query 在多个反事实证据集合上的 sufficiency stability、answer consistency 和 orbit alignment，而不是只看 clean query 或单一证据集合。

参考起点是 CoRM-RAG: *Beyond Semantic Relevance: Counterfactual Risk Minimization for Robust Retrieval-Augmented Generation*。当前工作不是直接声称完整复现并超越 CoRM-RAG，而是先构建一个 released CoRM critic 上的 counterfactual orbit bridge evaluation，验证 CSRM 是否比 clean-only、single-set sufficiency 和 naive orbit aggregation 更能识别 fragile RAG cases。

## 2. 当前论文级主张边界

当前可以主张：

- CSRM 在 HotpotQA-derived counterfactual orbits 上显著优于 clean-only CoRM critic、SURE-style single-set sufficiency 和 naive orbit average。
- CSRM 在 FEVER v3 near-miss counterfactual stress split 上也有二级 bridge evidence。
- shuffled perturbation ablation 崩掉，说明提升依赖正确的 orbit alignment，而不是简单增加 verifier 调用次数。
- NLI cross-scorer probe 中 CSRM 仍保持方向性优势，说明信号不完全依赖原始 CoRM-derived features。
- Hotpot-only conservative Clopper-Pearson risk-control pressure test 支持 empirical transfer，但不能推出 general formal guarantee。

当前不能主张：

- 不能说已完整复现 CoRM-RAG end-to-end retrieval-generation。
- 不能说有 general formal risk-control guarantee。
- 不能说结果已经 human-audited。
- 不能说 robust RAG 被普遍解决。
- 不能说所有实验 all win。

- Hotpot 主结果很强。

## 14. 2026-05-28 v4 去捷径诊断补充

本轮新增了 leakage-free v4 的 retrieval-score controlled diagnostic，目的是检验 Hotpot / FEVER v4 smoke 结果是否依赖可见 retrieval score 或结构长度捷径。新增脚本：

- `experiments/build_v4_score_controlled_variant.py`
- `tests/test_build_v4_score_controlled_variant.py`

脚本只生成新的 raw 变体，不覆盖原始 v4 文件。`constant` 模式会把所有可见 `retrieval_score` 固定为 0.5，并同步更新 `retrieval_scores` 汇总字段；该设置只用于 anti-shortcut 诊断，不应替代真实检索证据。

### 14.1 Constant-score 诊断结果

| Setting | n | Structural-only max AUROC | Pass <=0.55 | CSRM AUROC | Risk@30 | AURC | CSRM vs naive AUROC delta |
|---|---:|---:|---|---:|---:|---:|---:|

| Hotpot v4 smoke + constant score + matched | 6 | 0.5556 | false | 0.5556 | 0.5000 | 0.3028 | -0.1111 |

| FEVER v4 smoke + constant score + matched | 8 | 0.8125 | false | 1.0000 | 0.0000 | 0.1438 | 0.3750 |

### 14.2 解释

- Hotpot 去掉 retrieval-score 后，结构捷径基本受控，但 CSRM 排序优势也基本消失；这说明 Hotpot v4 smoke 当前不能作为强正证据，只能作为去捷径诊断样例。
- FEVER 去掉 retrieval-score 后，CSRM 仍显示 AUROC 1.0，但 anti-shortcut 仍失败，主要残留捷径变成 `mean_doc_chars` / `total_doc_chars`，matched 子集也未能压到 0.55 以下。
